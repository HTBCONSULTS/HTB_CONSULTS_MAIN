HTB Consult - Hero Video Background Directory
==============================================
Place your video file here:
File path: /media/hero-loop.mp4  (or configured in src/config/videoConfig.ts)

Recommended video specifications:
- Format: MP4 (H.264 / AAC)
- Resolution: 1920x1080 (1080p) or 1280x720 (720p)
- Framerate: 24fps or 30fps
- Optimization: Web-optimized / fast start enabled
- Visual style: Ambient, slow corporate camera movement, subtle corporate office / UK skyline
- The website is already wired to automatically detect and play the video when present, muted, looping, and paused if the user has enabled prefers-reduced-motion. When no video is present, the website seamlessly displays the high-fidelity executive poster image.
